# Home Assistant app (add-on): My Bank API

![Supports aarch64 Architecture][aarch64-shield] ![Supports amd64 Architecture][amd64-shield]

Self-hosted personal finance backend for the [My Bank](https://github.com/Patafoin/ha-my-bank) integration: accounts with three balances (total, cleared, reconciled), split transactions, transfers, hierarchical categories, scheduled transactions, budgets and shared expenses.

The app announces itself to Home Assistant: once the My Bank integration is installed (HACS), it is set up with one click.

See the **Documentation** tab for details.
