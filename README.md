# Patafoin Home Assistant add-ons

[![Open your Home Assistant instance and show the add add-on repository dialog with this repository URL pre-filled.](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FPatafoin%2Fha-addons)

| Add-on | Description |
|---|---|
| [My Bank API](my_bank_api/) | Personal finance backend for the [My Bank](https://github.com/Patafoin/ha-my-bank) integration |

## Installation

Settings → Add-ons → Add-on store → ⋮ → Repositories → add `https://github.com/Patafoin/ha-addons`, or use the button above.

The add-on uses the multi-architecture image `ghcr.io/patafoin/my-bank-api`, built from the [my-bank-api](https://github.com/Patafoin/my-bank-api) repository.
